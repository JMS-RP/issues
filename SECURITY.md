# Security Policy

This repository is a public issue tracker. Do not publish credentials, private player information, private infrastructure details, or actionable exploit instructions.

Security-sensitive reports include:

- Permission or ACE bypasses
- Money, item, XP, or vehicle duplication
- Client-authority exploits
- Authentication or account-linking problems
- Private data exposure
- Malicious resource or event abuse
- Exploitable server crashes or denial-of-service behaviour

Please report these privately through the official [JMS RP Discord](https://discord.gg/hPBSaBggJ9). Mark the message as security-sensitive and include enough detail for staff to reproduce the issue safely.

For ordinary bugs and suggestions, use a public GitHub issue.
