# Contributing to JMS-RP Issues

Thank you for helping improve JMS RP.

This repository is intentionally public so testers, players, staff, and developers can give feedback in one visible place.

## Issue quality

Before opening a new issue:

- Search for an existing report or suggestion.
- Use the most specific title you can.
- Select the closest script or affected area.
- Provide exact reproduction steps for bugs.
- Separate the expected result from the actual result.
- Include the build, branch, or server environment when known.
- Attach redacted screenshots, video, F8 output, or server logs where helpful.

## Bug reports

A bug report should describe a reproducible problem, not only a conclusion.

Good:

> Opening the public garage at Legion Square, selecting a stored vehicle, and pressing Retrieve closes the menu but does not spawn the vehicle. This happens three times on the staging server after reconnecting.

Weak:

> Garages broken.

## Suggestions

Explain the problem before proposing the solution. Suggestions are easier to evaluate when they include:

- The current limitation
- The proposed change
- The expected benefit
- Any affected scripts, jobs, or player groups
- Possible edge cases or trade-offs

## Follow-up

The JMS RP team may ask for more information, change labels, merge duplicates, or close reports that are not reproducible, no longer apply, or belong in private support.

Please keep discussion constructive and focused on the product.

## Do not post sensitive information

Never publish:

- Passwords, API keys, tokens, or private URLs
- Player personal information
- Private server addresses or infrastructure details
- Unredacted screenshots containing sensitive information
- Public exploit instructions for security-sensitive issues

Use the private security-report route in the README instead.
